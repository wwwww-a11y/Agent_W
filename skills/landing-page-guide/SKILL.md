# 一页式落地页需求模板

这是一个不绑定内置动作的纯提示词技能：调用时只展示下面这份模板，
帮你把网页需求写得更完整。复制后替换括号内容即可。

## 需求模板

```
页面类型：（产品宣传 / 个人主页 / 活动报名 / 作品展示）
整体风格：（配色、明暗、字体气质）
首屏内容：（主标题、副标题、主按钮文案）
板块划分：（如：产品介绍 → 优势 → 客户案例 → 联系方式）
需要素材：（图标、图片占位、配色偏好）
页脚信息：（联系方式、备案、社交链接）
```

## 写作要点

- 先讲清页面目的，再描述视觉风格。
- 列出必须出现的板块顺序，避免生成时遗漏。
- 明确交互诉求（如悬停效果、表单、轮播）。
